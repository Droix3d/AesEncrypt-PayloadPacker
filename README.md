# AesEncrypt-PayloadPacker
This function handles runtime payload decryption using a lightweight implementation of the Advanced Encryption Standard (AES) in Cipher Block Chaining (CBC) mode.

Key Steps Performed:Validation & Alignment Check:Verifies that all required pointers, size parameters, key, and Initialization Vector (IV) are present.Ensures the ciphertext size is a strict multiple of the AES block size ($16$ bytes), which is required for block cipher decryption.Buffer Allocation & Copy:Allocates a dynamic heap buffer matching the size of the ciphertext and securely duplicates the encrypted payload data into it.Context Initialization & Decryption:Initializes the AES context structure (AES_ctx) using the provided $32$-byte key and $16$-byte IV (AES_init_ctx_iv).Performs in-place buffer decryption utilizing CBC mode (AES_CBC_decrypt_buffer).Padding Strip & Final Size Calculation:Reads the final byte of the decrypted data to determine the padding length (bPadLen).Validates the padding length and calculates the true unpadded plaintext size (dwCipherSize - bPadLen) before returning the clean payload pointer and its adjusted size for execution.
